# GitHub Auto-Sync

- Always commit and push project changes to GitHub (`origin main` at `https://github.com/Mani632/buildwithgemini-wanderwise`) upon completing code edits, new tools, configuration changes, or deployments.
- Use meaningful commit messages summarizing the modification.
- Ensure `PATH="$HOME/.local/bin:$PATH"` and `gh auth setup-git` are configured when pushing.
